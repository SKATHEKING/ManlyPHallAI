## Suggested Weekly Notes

Record these items each week:

- What concept clicked most clearly.
- What concept still felt confusing.
- Which file in the repo was most useful.
- Which external resource was most helpful.
- What you would change if you rebuilt that layer from scratch.

## Lightweight Review Questions

At the end of each week, answer these:

- What problem is this layer solving?
- How does it connect to the previous layer?
- What trade-off did the project make?
- What would break if this layer failed?
- What is the smallest experiment I can run next?

## Suggested Time Block

- 30 minutes: read docs and code
- 30 minutes: read external resource
- 30 minutes: write notes or a diagram
- 30 minutes: do one small hands-on check
